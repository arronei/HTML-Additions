Formatter attribute

Live versions of the examples in the Formatter Attribute spec, running on formatter-attribute.js. Under each form is what the form would submit, updated as you type.

Area code

Type 206. The field shows 206 and validates 206, but the form submits (206). Clear it to submit an empty value.

Country calling code

The option values are plain numbers; the formatter adds the plus sign.

Amount

Type 25.50. The min and step attributes check the number; the server gets the currency too.

Tags

Select several options. Each selected value is formatted on its own.
